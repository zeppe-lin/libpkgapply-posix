# libpkgapply-posix

`libpkgapply-posix` provides the concrete POSIX mechanisms used by
`libpkgapply` application transactions.

This initial extraction preserves the mechanism bodies, public declarations,
behavior tests, and manual from the in-tree `libpkgapply` 2.3.0 product. The
following commits establish its independent repository, ABI, documentation,
and qualification contracts.
